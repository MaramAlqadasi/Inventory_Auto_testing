# reports/ — تقارير الإصلاح (مخرَج الـ Healer)

هنا تُوضَع **تقارير الإصلاح** التي يُنتجها وكيل **Healer** بعد تشغيل الاختبارات.

- الملف المتوقَّع: `healing-report.md`
- يحتوي على: المُحدِّدات التي فشلت + البديل المستقر المعتمَد + افتراضات الخطّة التي تبيّن خطؤها.

## حلقة التغذية الراجعة
كل مُحدِّد يُصلَّح هنا يُنقَل إلى:
1. `../project-context.md` (قسم استراتيجية المُحدِّدات) — فلا يتكرّر الفشل.
2. `../pages/*` (كائن الصفحة المعني).

> ملاحظة: تقارير Playwright الآلية (HTML/نتائج التشغيل) تبقى في `../playwright-report/` و`../test-results/` وهي مُولَّدة تلقائيًا (مذكورة في `.gitignore`).
