# pages/ — كائنات الصفحات (Page Object Model)

هنا تُوضَع **كائنات الصفحات (POM)** التي يُنتجها وكيل **Generator** مع سكربتات الاختبار.

- لكل صفحة كائن مستقل، مثال: `ProductsPage.ts` / `LoginPage.ts`.
- يحتوي على المُحدِّدات (selectors) والأفعال (actions) القابلة لإعادة الاستخدام.
- الهدف: عند تغيّر مُحدِّد، يُصلَّح في مكان واحد فقط (يقلّل عمل الـ Healer).

➡️ تُستهلَك من `../tests/*.spec`. أي مُحدِّد يُصلِّحه الـ Healer يُحدَّث هنا وفي `../project-context.md`.
