# specs/ — خطط الاختبار (مخرَج الـ Planner)

هنا تُوضَع **خطط الاختبار** التي يُنتجها وكيل **Planner**.

- الملف الأساسي المتوقَّع: `test-plan.md`
- لكل صفحة/ميزة خطّة مستقلة، مثال: `products-index.test-plan.md`

## ما يجب أن تحتويه الخطّة (حسب `qa-agents/orchestration.md`)
- النطاق (Scope) وما هو خارج النطاق.
- تقييم المخاطر وأولويات الاختبار.
- جدول حالات الاختبار (ID · العنوان · الخطوات · النتيجة المتوقَّعة · الأولوية).
- بيانات الاختبار المستخدمة (صالحة/حدّية/سلبية).
- **استراتيجية المُحدِّدات (selectors) لكل عنصر** — تُقرَّر هنا لا في الكود.
- مصفوفة التتبّع (requirement ↔ test case).
- الافتراضات التي تحتاج تأكيدًا.

➡️ المُدخل: `../project-context.md` — المُخرَج يُستهلَك من وكيل **Generator** لتوليد `../tests/*.spec`.
